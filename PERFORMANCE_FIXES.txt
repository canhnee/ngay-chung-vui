3. CÁCH DEPLOY LÊN VERCEL
===================

1. Push code lên Git:
   git add .
   git commit -m "Fix audio and optimize performance"
   git push

2. Deploy lên Vercel:
   - Vào vercel.com
   - Kết nối repository
   - Vercel sẽ tự động build và deploy
   - vercel.json đã được cấu hình sẵn

3. Sau khi deploy:
   - Test audio trên URL production
   - Kiểm tra network tab để xem lazy loading hoạt động
   - Các ảnh chỉ load khi scroll đến

===================
4. HƯỚNG DẪN TỐI ƯU THÊM (TÙY CHỌN)
===================

Nếu vẫn thấy chậm, có thể:

1. Chuyển ảnh sang WebP format (giảm 70% dung lượng):
   - Dùng tool online: squoosh.app
   - Convert tất cả .JPG thành .webp
   - Update đường dẫn trong fallbackWedding.ts

2. Upload ảnh lên CDN:
   - Cloudinary (free 25GB)
   - ImageKit (free 20GB)
   - Hoặc Supabase Storage
   - Thay đổi image_url trong database

3. Compress audio:
   - Hiện tại: 4MB MP3
   - Có thể giảm xuống 2MB với quality tốt
   - Dùng Audacity hoặc online tool
